# Celestial Tower
Dreamy 1-Star minihack in which you play as Yoshi.

 <source media="(prefers-color-scheme: dark)" srcset="https://kuribo64.net/get.php?id=ZWq2JU8sm4s3lnfW">

</picture>

The hack is supplied an an xDelta patch. Apply this patch to a **clean European ROM of SM64DS** to play the game.
Works on original hardware and emulator.
<br/><br/>

**KNOWN ISSUES:**
- Flags on file select screen are still visible.
